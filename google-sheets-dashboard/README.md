# Google Sheets Live Budget Dashboard

공개(링크가 있으면 누구나 보기) 구글 시트를 백엔드 없이 브라우저에서 바로 읽어와
실시간처럼(10초 주기 자동 폴링) 보여주는 정적 예산 대시보드입니다.

## 사용법

1. `index.html`을 브라우저로 열면 바로 동작합니다 (`file://`로 열어도 됨 — 서버 불필요).
2. 시트를 수정하면 다음 폴링 주기(기본 10초) 안에 대시보드가 자동으로 갱신됩니다.
3. 우측 상단 "지금 새로고침" 버튼으로 즉시 갱신할 수도 있습니다.

## 다른 시트 / 예산에 연결하기

`index.html` 상단의 설정만 바꾸면 됩니다.

```js
const SHEET_ID = '스프레드시트 URL의 /d/ 다음 긴 문자열';

// 월별로 탭이 나뉘어 있을 때, 새 탭을 만들 때마다 여기에 { 월숫자: gid } 한 줄만 추가하면
// 오늘 날짜(월)에 맞는 탭을 자동으로 골라 씁니다. gid는 그 탭을 연 상태에서 브라우저
// 주소창 끝의 #gid=숫자 부분을 복사하면 됩니다.
const GID_BY_MONTH = {
  7: 1408217412, // Jul
};
const GID = null;               // 이번 달이 위 목록에 없을 때 대신 쓸 gid. null이면 첫 번째 탭.
const POLL_INTERVAL_MS = 10000; // 폴링 주기 (ms)
const TOTAL_BUDGET = null;      // 고정 금액을 쓰려면 숫자 입력(예: 1000000). null이면 아래 BUDGET_LABEL로 시트에서 자동으로 찾음.
const BUDGET_LABEL = 'Target Budget'; // 시트에서 이 텍스트가 적힌 셀을 찾아 바로 오른쪽 칸의 숫자를 예산으로 사용
```

시트는 반드시 **"링크가 있는 모든 사용자에게 공개(뷰어)"** 로 공유되어 있어야 합니다.
비공개 시트는 이 방식(JSONP)으로 읽을 수 없습니다.

새 달의 탭을 만들었으면, `GID_BY_MONTH`에 `{ 8: 그_탭의_gid }` 처럼 한 줄만 추가하면 그 달이
되는 순간 대시보드가 자동으로 그 탭을 읽기 시작합니다.

`GID_BY_MONTH`에 등록된 달이 하나라도 있으면 우측 상단에 월 선택 드롭다운이 나타나서,
이번 달이 아닌 다른 달 데이터도 대시보드 안에서 바로 골라볼 수 있습니다.

## 화면 구성

- 상단 상태 표시줄: 연결 상태(초록 점 = 정상, 빨간 점 = 최근 갱신 실패) + 마지막 업데이트 시각
- **예산 카드**: 남은 예산 hero 숫자, 사용률 진행바, 상태 배지
  - 기본값은 시트에서 `BUDGET_LABEL`(기본 `Target Budget`) 텍스트가 적힌 셀을 찾아 바로 옆 칸의
    숫자를 예산으로 사용 — 월급에 따라 예산이 매달 바뀌어도 시트만 갱신하면 자동으로 반영됨
  - `TOTAL_BUDGET`에 숫자를 직접 넣으면 그 고정값을 우선 사용
  - 사용률 80% 미만 = "여유 있음"(초록), 80~100% = "주의 필요"(노랑), 100% 이상 = "예산 초과"(빨강)
  - 색만으로 상태를 구분하지 않도록 아이콘(✓/⚠/✕) + 텍스트 라벨을 항상 함께 표시
- 통계 타일: 전체 행 수, 숫자형 컬럼별 합계/평균 (자동 감지)
- 차트: 시트에 날짜형 컬럼이 있으면 시계열 라인 차트, 없고 문자열 컬럼이 있으면
  카테고리별 막대 차트를 자동으로 그립니다 (상위 7개 + "기타")
- 표: 전체 원본 데이터, 헤더 클릭으로 정렬 가능

지출 총액은 시트에서 감지된 **첫 번째 숫자형 컬럼의 합계**를 기준으로 계산합니다
(예: "금액"이나 "지출" 컬럼이 첫 숫자 컬럼이 되도록 시트를 구성하면 됩니다).
컬럼 이름이나 개수를 하드코딩하지 않으므로 시트 구조가 바뀌어도 대부분 그대로 동작합니다.

## 동작 원리

구글 시트의 `gviz/tq` 엔드포인트는 CORS 헤더를 내려주지 않아 `fetch()`로는 못 읽습니다.
대신 `<script>` 태그로 불러오는 JSONP 방식(`responseHandler` 콜백)을 사용해 브라우저에서
직접 데이터를 가져옵니다. 별도 백엔드/배포가 필요 없는 대신, 반드시 공개 시트여야 합니다.

## 한계 / 다음 단계

- **폴링 방식**이라 완전한 실시간(수정 즉시 push)은 아니고, 최대 `POLL_INTERVAL_MS`만큼의
  지연이 있습니다. 대부분의 예산 관리 용도로는 충분합니다.
- 예산은 현재 **전체 단일 금액**만 지원합니다. 카테고리별 예산을 걸고 싶다면 시트에
  카테고리별 목표 금액 컬럼(또는 별도 탭)을 추가하고, 카테고리별 진행바로 확장할 수 있습니다.
- 시트를 비공개로 바꾸거나, 수정 즉시(0초 지연) 반영이 필요하다면 Apps Script의 `onEdit`
  트리거로 웹훅을 쏘고, 이를 받아 프론트로 push(WebSocket/SSE)하는 백엔드가 별도로
  필요합니다 — 배포 환경(Netlify 등)이 정해지면 추가로 구현할 수 있습니다.
